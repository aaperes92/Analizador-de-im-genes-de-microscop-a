# Analizador-de-im-genes-de-microscop-a
EL programa contiene herramientas para analizar imágenes obtenidas mediante técnicas de microscopía, incluyendo TEM, SEM y Microscopía MOKE. Comprende funciones para procesar imágenes, segmentarlas y extraer información relevante sobre la composición de las muestras e información de los dominios.
